# EdgeLink 1.0.1

- Исправлен повторный запуск сервера Mac: остановленный сервер освобождает Ethernet-порты даже без подключённого ПК.
- На Windows рабочий стол больше не блокирует переход курсора как полноэкранная игра. Обработка ввода и автоподключение запускаются независимо от открытия окна; сворачивание в трей сохраняет переподключение.
- Поиск Mac повторяет потерянные запросы и пропускает посторонние ответы. Запоздалые ошибки предыдущего аудиовыхода не разрывают новое соединение.
- Обновления заменяют установленное приложение без резервных копий и удаляют временные файлы. Новая версия также удаляет строго распознаваемые копии старого обновлятора после запуска.
- Новые иконки EL на обеих платформах, обновлённый интерфейс Windows и настройка Keep Awake на Mac.

Обновление: откройте EdgeLink → **Проверить обновления** → **Установить**. Настройки и сопряжение сохраняются. Если на Mac уже установлен 1.0.1, повторная установка не требуется.

Windows: один самодостаточный `EdgeLink.exe`, Windows x64. Mac: Apple Silicon, macOS 15 или новее.

Проверки: нативные ввод/трей/WinUI на Windows-сервере GitHub Actions, Windows PowerShell 5.1 / NTFS установка, Swift/.NET совместимость протокола и нативная установленная Mac-сборка. Реальные переходы, звук в наушниках и поведение игр на пользовательском ПК после этого обновления требуют проверки с подключённым Ethernet.
