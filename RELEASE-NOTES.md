# EdgeLink 1.0.2

- Обновлён интерфейс Mac и Windows: компактная схема MacBook/ПК, простые строки состояния клавиатуры, мыши и звука, моноширинные подписи и спокойный зелёный акцент.
- Mac: нативный верхний переключатель разделов без боковой панели, стандартные кнопки и переключатели macOS. Дизайн утверждён пользователем.
- Windows: нативные элементы WinUI и верхняя навигация, системная светлая/тёмная тема и соответствующее оформление заголовка. Компактные параметры и главное окно.
- Плавное появление страниц и обновление статусов учитывают системное отключение анимаций. Диагностика соединения свёрнута по умолчанию; её таймер работает только при открытой диагностике и видимом подключённом окне.

Установите через «Параметры» → «Проверить обновления» → «Установить». Ключ подключения и настройки сохраняются. Установщик заменяет приложение без резервной копии старой версии.

Файлы: `EdgeLink-macos-arm64.zip` для Apple Silicon; `EdgeLink-windows-x64.zip` или прямой `EdgeLink.exe` для Windows x64. Windows EXE самодостаточный, отдельный runtime устанавливать не нужно.

Сборки проходят программные и нативные проверки интерфейса/ввода/трея/установщика. Windows-проверки выполняются на сервере GitHub Actions; аппаратные переходы курсора и слышимое качество звука на пользовательском ПК для этого релиза ещё не перепроверены.
