# EdgeLink: Mac → Windows handoff

Дата: 11 октября 2026, Asia/Dubai. Ветка: `mac/el-icon-validation`.

## Текущее состояние: Keep Awake на Mac

По запросу пользователя добавлен Keep Awake: переключатель на главной странице и пункт меню EL «Keep Awake — не давать Mac уснуть». Функция включена по умолчанию; выбор сохраняется в локальном UserDefaults и применяется при каждом запуске. Она работает всё время жизни EdgeLink, включая ожидание ПК и скрытое окно, независимо от состояния связи.

Используется один process-owned `IOPMAssertionTypePreventUserIdleDisplaySleep`, который предотвращает автоматический сон экрана и тем самым idle system sleep. Таймеры, имитация ввода и дочерний caffeinate не нужны. При выключении и `applicationWillTerminate` assertion освобождается; deinit также освобождает его. Preview не создаёт assertion. Явный сон, закрытие крышки и штатная политика питания macOS не переопределяются. Основание: [Apple IOKit](https://developer.apple.com/documentation/iokit/kiopmassertiontypepreventuseridledisplaysleep) и локальный SDK IOPMLib.h.

Проверенные и установленные исходники: `aa2763fe7ac76604eaf2121db24d0552bf219fe5`, версия 1.0.0. Нативная проверка IOKit **10/10**: создание, тип/уровень assertion, повторное включение без дубликата, выключение, повторное выключение, повторное включение и deinit. Она включена в `source/run-checks.sh`; полный прогон Swift/.NET с `EDGELINK_SKIP_DISCOVERY_CHECK=1` завершился exit 0. Проверка иконок bundle — 11/11; ресурсы и протокол не менялись.

Сборка установлена в `/Applications/EdgeLink.app` после штатного выхода; прежняя версия сохранена локально вне Git. Подпись сохранена, TCC и ключ сопряжения не менялись. На настоящем интерфейсе macOS проверены видимость карточки, переключение on/off и пояснения. Через `pmset -g assertions` подтверждены отсутствие assertion после выключения, ровно один после включения и отсутствие после выхода. Проверены перезапуски с выключенным и включённым выбором. Итоговая установка оставлена запущенной с Keep Awake **включённым**. После замены связь с ПК восстановилась автоматически; новые физические проверки клавиатуры/курсора и прослушивание звука не заявляются. Пункт глобального меню EL добавлен и собран; его интерактивное нажатие инструментом не проверялось.

Результаты: [`validation/mac-keep-awake-2026-10-11/`](validation/mac-keep-awake-2026-10-11/). SHA-256 executable: `2b1dc6f2c0e6b3236f93ee6452b1fbfb5380685531490ecafa8cff140a14f6f1`. Полный цикл ожидания реального idle sleep, закрытие крышки и принудительный сон не выполнялись, чтобы не прерывать рабочую сессию; проверено состояние штатного assertion, а не обещана блокировка всех видов сна.

Windows-код не менялся; новый Windows EXE ради этой функции не требуется. Ветка обмена остаётся `mac/el-icon-validation`. Публичный релиз/OTA остаётся v0.3.4; эта проверочная Mac-сборка 1.0.0 обновлена локально.

## Изменения Mac

- `ced57a8`: повторный запуск приложения открывает ранее закрытое окно через `applicationShouldHandleReopen`; добавлена нативная проверка ресурсов AppKit.

Генератор теперь упаковывает PNG в стандартные ICNS chunks. В этом прогоне ICNS пересобран из включённых в Git PNG через тот же `write_icns`; весь генератор с Pillow повторно не запускался. Windows ICO/PNG не менялись.
- `c6349d8`: по замечанию пользователя EL в строке меню уменьшен с 23×18 до 18×14 pt. Ресурсы 23×18 и 46×36 px остаются в bundle, изображение загружается как `EdgeLinkStatus` с `isTemplate = true`. Шапка использует прежний `AppIcon` 42×42 pt.
