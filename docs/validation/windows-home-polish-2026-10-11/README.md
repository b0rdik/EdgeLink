# Windows: главная WinUI и навигация

Дата: 11 октября 2026. Исходники: `eee8ca331e5771f8fa74e3bcf42ff6c5460aed66`, ветка `windows/input-validation`, версия 0.3.4. Физический Windows 11 Pro 25H2, build 26200.9457; 2560×1440 / 180 Гц / 96 DPI. .NET SDK 10.0.401.

Изменения: фон за карточками, отступы подсказки про трей, статистика на главной вместо параметров, иконки ноутбука Mac и монитора Windows. NavigationView занимает отдельную неподвижную строку. Вместо встроенного растягивающегося индикатора используется одна полоска постоянной ширины, движущаяся через нативную Composition Translation за 160 мс. Новая выборка отменяет устаревшее отложенное открытие страницы. Размер окна по умолчанию 880×900, ограничен рабочей областью.

Сборка:

```powershell
dotnet publish source/windows/EdgeLink.csproj -c Release -r win-x64 --self-contained true -p:PublishReadyToRun=false -p:TreatWarningsAsErrors=true -o Windows
```

Все диагностические режимы выполнены последовательно после полного штатного выхода обычного EdgeLink и проверки отсутствия процесса. Финальные input/layout/tray завершились с кодом 0. Полный .NET/Swift набор не повторялся: код протокола, сети, ввода и звука не менялся.

| Файл | Результат |

| `input-checks.json` | 4/4; отдельный поток ввода, Raw Input, блокировка основного потока, очередь и перезапуски |

Layout дополнен проверкой нижней подсказки и статистики на главной, а также очередью шести смен вкладок с проверкой последнего выбора и постоянных границ навигации. PNG созданы RenderTargetBitmap в диагностическом режиме, без пользовательских настроек, ключей, устройства вывода и сетевого соединения. Во всех случаях доступны вертикальная прокрутка и полный текст. PNG не измеряют плавность анимации. Shutdown/updater в tray checks — проверка условий, фактическое завершение Windows и установка обновления не выполнялись.

Через Computer Use просмотрены настоящие WinUI-окна, переключение мышью и положения полоски после движения. Финальный EXE на рабочем столе автоматически подключился к Mac. Главная целиком помещается в начальном окне, счётчики меняются. Нажатие крестика: тот же PID 24868, MainWindowHandle=0. Повторный настоящий запуск: Exit 0, восстановлен PID 24868 и окно. Аудиопакеты на снимках 1604 → 3216, прерывания 0 → 0. Прослушивание и аппаратные измерения не выполнялись.

Первый вариант с сохранением стандартного индикатора пользователь оценил как всё ещё дёргающийся; в финальных исходниках этот эффект заменён перемещением одной полоски. После проверки установленной финальной сборки пользователь подтвердил: «Теперь плавно и нормально». Это пользовательская оценка анимации вкладок, без инструментального измерения частоты кадров. Новые проверки физической Lamzu/MCHOSE/Dark Project не заявляются. Предыдущее подтверждение 4000 Гц / хорошего курсора и звука сохранено в основном handoff; 8000 Гц и другие DPI пока не проверены.
