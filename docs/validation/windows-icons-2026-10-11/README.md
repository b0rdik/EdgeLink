# Иконка EL: Windows и общие ресурсы

Исходники: `3d001b70b2b17c630ac68d43c9f6d6efda2c87ea`, ветка `windows/input-validation`, версия 0.3.4. Проверки 11 октября 2026 выполнены локально на физическом Windows-ПК (Windows 11 Pro 25H2 / 96 DPI).

Иконка: [SVG](../../../source/assets/EdgeLink.svg), [PNG 256](../../../source/assets/icon-256.png). Бирюзовые стилизованные E/L, скруглённые штрихи одной толщины, тёмная плитка; исходная геометрия общая для обеих платформ.

## Результаты

- Release win-x64, self-contained, .NET SDK 10.0.401, `TreatWarningsAsErrors=true`: успешно, без предупреждений.
- `resource-checks.json`: девять RGBA PNG с прозрачными углами, семь размеров ICO 16–256, восемь декодируемых представлений ICNS, чёрные альфа-шаблоны меню Mac 23×18 и 46×36. Все семь ресурсов RT_ICON нативной PE-группы 32512 в финальном EXE совпадают с соответствующими исходными PNG по SHA-256. Проверка PE выполнялась Win32 API LoadLibraryExW/EnumResourceNamesW/FindResourceW в режиме data file.
- `tray-checks.json`: после полного штатного выхода обычного приложения `EdgeLink.exe --tray-checks` завершился с кодом 0, 8/8 PASS. Это проверка регистрации настоящего значка Shell и поведения окна; shutdown/installer проверяют условия закрытия, реальное завершение Windows или установка обновления не выполнялись.
- Финальный EXE установлен и запущен с рабочего стола. В живом окне через Computer Use проверены монограмма в шапке и заголовке, подключение к Mac и обновление статистики; аудиопрерывания на снимке — 0. Прямой визуальный просмотр системного трея не выполнялся.

ProductVersion установленного EXE: `0.3.4+3d001b70b2b17c630ac68d43c9f6d6efda2c87ea`. Размер: 234 416 175 байт. SHA-256: `928523bfce8700d3054d382fd7bb2bee28b314a7443cbc073ebb44b683895085`.

## Ограничения и следующий шаг

Mac ICNS и шаблоны подготовлены; `build-mac.sh` копирует шаблоны в bundle, `App.swift` использует template image. Здесь Mac не собирался и не запускался. Mac-чату получить ветку, собрать `bash source/build-mac.sh` и проверить Dock, Finder, шапку и меню при 1x/2x, светлой/тёмной теме. Python/Pillow нужен только при изменении графики; готовые файлы уже включены в Git.

Изменение относится к иконке. Input/layout и сетевые тесты не повторялись; результаты предыдущего этапа сохранены в handoff. Аппаратная плавность, клавиатура и слышимое качество звука на этом этапе не измерялись. В отчётах нет ключей, токенов и личных настроек.
